RosaZulado (Pinkish-Blue)

Thesis
XAMPP

Thesis consisting of a fully functional web application built in with XAMPP Server (Apache, PHP, MariaDB) that autonomously extracts data on erotic products from major websites in Spain using web scraping techniques. It categorizes and indexes these products periodically to compare their prices and show the user the cheapest price for the product they are looking for.

RosaZulado (Pinkish-Blue) is the first web application that compares prices and offers from the main online stores of erotic toys, products, and accessories in Spain. It features a complex filtering system and an extensive database regularly updated to display products that match customer requests. The entire application is built with AJAX (no page reloads are required during interaction), an intelligent product search system that speeds up previously performed searches, product pagination displaying up to 50 products per page, and a security API designed exclusively for RosaZulado that virtually eliminates database injections instantly. These features ensure the fastest and smoothest user experience, allowing users to focus on finding the store offering the cheapest product they seek. Additionally, stores can view information related to their store, enabling them to analyze the most searched products and the user traffic received from RosaZulado. This data remains secure in their account thanks to the 128-bit random encryption system, securely storing their public key (username) and private key (password). Lastly, RosaZulado also offers a service for users seeking a toy tailored to their needs.

 

Source: Thesis: RosaZulado (Pinkish-Blue) (El comparador de precios y ofertas de juguetes eróticos), 1. Naturaleza Del Proyecto, 1.1 Descripción Del Proyecto
