Prism as a REST API testing server

NodeJS
API

Craiyon

Pablo Urrea

5 minutes reading
Published
15/04/2024

Prism simplifies REST API development by providing a realistic and controlled testing environment, without relying on external servers. An essential tool for REST API developers.

Often in the world of development, it becomes a race between the hare and the tortoise, and spoiler alert: you're not the hare. That's the case with REST API development, where API integrations arrive long before the API itself, and you need to provide a testing environment for that hare who's watching you while overtaking you and sends you an email every week asking for a solution. This is where Prism comes into play (Prisma for friends who don't want to pronounce it with a clenched jaw), an invaluable tool to simplify and streamline the REST API development process.

Prism is a REST API simulation server (Among its features) that allows you to define custom endpoints, simulate responses, and set up test scenarios for your applications using the YML interface of OpenAPI. With Prism, development teams can create a realistic and controlled testing environment without relying on external servers or production environments.

 

Express REST API. Setting up Prism is simple and fast. Once installed, you can easily define endpoints, specify response formats, and simulate different API states such as successful responses, errors, or wait times. Prism offers an intuitive interface that efficiently manages "fake" APIs or test APIs. With Prism, it's possible to define complex test scenarios, simulate dynamic data, and validate application behavior in different situations.

 

Installation like any other Node.js package. To start using Prism, you first need to install it in your development environment (Obviously). You can install Prism globally using NPM (Node Package Manager) with the following command:

npm install -g @stoplight/prism-cli

Alternatively, you can omit the -g parameter if you don't want Node packages to proliferate on your machine like rodents. If you need more installation options, you can check Prism's documentation.

 

Definitions. Once Prism is installed, you can configure it to simulate your REST API. Suppose you have an API with a /users endpoint that returns a list of users in JSON format, the following example YAML configuration file shows how to set up the simulation of this endpoint:

openapi: 3.0.0
info:
 title: Example REST API
 version: 1.0.0
paths:
 /users:
   get:
     summary: Gets the list of users
     responses:
       '200':
         description: Successful response
         content:
           application/json:
             schema:
               type: array
               items:
                 type: object
                 properties:
                   id:
                     type: integer
                   username:
                     type: string
                   email:
                     type: string

You can configure this file manually if you feel comfortable with the OpenAPI configuration interface or with any API design tool, such as SwaggerHub, for example.

 

Start your engines. To run Prism and simulate your REST API, you can do it with the following command (Remember to adjust openapi.yml to the path of the above configuration file):

prism mock openapi.yml

This will start the test server at the URL http://localhost:4010, although it accepts the following combinable parameters (The most useful ones):

  • -h: Modifies the IP address to the provided one. For example:

    prism mock -h 0.0.0.0 openapi.yml

  • -p: Modifies the network port to the provided one. For example:

    prism mock -p 9999 openapi.yml

  • --dynamic: Generates dynamic responses that match the provided schema. For example:

    prism mock --dynamic openapi.yml

Once the server is started, you can make requests to the service from your machine to the local IP (Or to the IP of the remote machine if installed on a remote server):

curl http://localhost:4010/users

Prism accepts configurations for GET, POST, PUT, PATCH, and DELETE methods.


Conclusion. Prism is an indispensable tool for any development team working with REST APIs. By simplifying the development and testing process, it enables teams to create high-quality applications more quickly and efficiently. With its features and ease of use, Prism has become the perfect companion for any developer looking to improve their API development workflow (Or if you simply don't want to fall behind like the tortoise).

 

If you need more information about the package, you can check Prism's documentation.
