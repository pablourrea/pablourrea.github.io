Configure Fortinet VPN on Linux

VPN
Linux

Pablo Urrea

9 minutes reading
Published
20/07/2024

FortiClient

Download and run. The easiest way to access the Fortinet VPN is to download the FortiClient executable and install it from its official page.

This is probably the method recommended by your company's IT department if you are downloading it for work, as it is universal and works on Windows, MacOS, iOS, Linux, and Android at the time of publishing this article.

Configuring FortiClient and connecting to the VPN is as simple as following the steps in the graphical interface:

While there are many advantages to installing and using the Fortinet FortiClient on Linux, there are also some disadvantages, which are outlined below:
Advantages:

  • ➡ Quick and convenient installation.
  • ➡ Cross-platform, with each system having its corresponding installation method.
  • ➡ Easy to configure and use thanks to the graphical interface.


Disadvantages:

  • ➡ Depending on your Linux system configuration, you will likely need to enter your Fortinet password each time you want to start the connection.
  • ➡ Neglects the native VPN configuration of Linux and leaves an icon in the system tray (fortitray).
  • ➡ Automation is difficult to configure.

 

Linux Console

What would the penguin's operating system be without its console? The most “Linux” way to access the Fortinet VPN is through the system console, but it requires following a few steps. First, you need to install the Fortinet package, as it likely isn’t installed by default, so execute the following commands in the console:

sudo apt update
sudo apt install network-manager-fortisslvpn-gnome

Next, to connect, you need to provide a security certificate hash. The easiest way to obtain it is by inducing an error with the connection command. To do this, run the following command, replacing IP_ADDRESS, NETWORK_PORT, YOUR_USERNAME, and YOUR_PASSWORD with your Fortinet account values:

sudo openfortivpn IP_ADDRESS:NETWORK_PORT --username=YOUR_USERNAME --password=YOUR_PASSWORD

This should generate an error in the console output due to the absence of a trusted certificate. Look for a line similar to:

ERROR:      --trusted-cert 0123456789abcdefghijklmnopqrstuvwxyz

Each Linux machine has its own trusted certificate hash. To connect, simply repeat the previous command and add the trusted certificate parameter obtained from the error:

sudo openfortivpn IP_ADDRESS:NETWORK_PORT --username=YOUR_USERNAME --password=YOUR_PASSWORD --trusted-cert 0123456789abcdefghijklmnopqrstuvwxyz

 

While there are many advantages to installing and using the Fortinet VPN via the Linux console, there are also some disadvantages, which are outlined below:
Advantages:

  • ➡ Quick installation via console.
  • ➡ Connection can be automated.
  • ➡ Does not require the system's graphical interface. (Advantage and disadvantage)


Disadvantages:

  • ➡ Requires using the Linux console.
  • ➡ Complex to use.
  • ➡ Does not require the system's graphical interface. (Advantage and disadvantage)

 

Linux Network Connections

Like any other network connection. Adding the Fortinet VPN to the list of Linux networks is probably the most convenient way to connect, as it is added as a VPN to your WiFi networks, and connecting is as simple as accessing a WiFi network.

The graphical layout and texts of the configurations vary depending on the Linux distribution. For this guide, I will use Kubuntu 22.04 LTS. First, install the Fortinet package, as it is likely not installed by default. Execute the following commands in the console:

sudo apt update
sudo apt install network-manager-fortisslvpn-gnome

Next, to configure the VPN connection, you need to provide a security certificate hash. The easiest way to obtain it is by inducing an error with the connection command. To do this, run the following command, replacing IP_ADDRESS, NETWORK_PORT, YOUR_USERNAME, and YOUR_PASSWORD with your Fortinet account values:

sudo openfortivpn IP_ADDRESS:NETWORK_PORT --username=YOUR_USERNAME --password=YOUR_PASSWORD

This should generate an error in the console output due to the absence of a trusted certificate. Look for a line similar to:

ERROR:      --trusted-cert 0123456789abcdefghijklmnopqrstuvwxyz

Copy the trusted certificate hash obtained from the error, as it will be needed later.

Now, you need to create the VPN connection. You can access the network connection settings from system settings or by right-clicking on the WiFi icon in the taskbar. Once in the settings, look for the “+” button or “Add new connection” and a window with multiple connection options will open. Under the “VPN Connections” group or section, select a connection called “Fortinet SSLVPN (fortisslvpn)” and click “Create”. This will open the VPN network configuration window.

For the connection name, you can choose any value you prefer; this will later appear in the network connections along with the VPN connection type icon. The gateway should be the VPN IP address, and if you have a port, it should be included after the IP address separated by “:”, resulting in “IP_ADDRESS:NETWORK_PORT”. The username and password should be the values of your Fortinet account. Depending on the Linux distribution, there will be sections, tabs, or buttons that open windows. After configuring “Advanced”, include the hash you copied from the console error in the trusted certificate field. After configuring “IPv4” > “Routes”, you should check the “Use only for resources on this connection” option to prevent it from affecting your other network connections.

After saving the VPN connection configuration, it should appear alongside the WiFi networks in its own section in settings, or with all connections if you click the network icon in the taskbar. To connect, simply click the “Connect” button.

While there are many advantages to installing and using the Fortinet VPN through Linux networks, there are also some disadvantages, which are outlined below:
Advantages:

  • ➡ Once installed, its use is very straightforward.
  • ➡ Does not require open windows during connection.
  • ➡ The interface integrates with the Linux distribution.


Disadvantages:

  • ➡ Requires using the Linux console.
  • ➡ Complex to configure and varies depending on the Linux distribution.
  • ➡ Automation is difficult to configure.

 

 

Conclusion. Fortinet offers various options for configuring and using its VPN on multiple platforms. Its installation is straightforward and quick, especially through the official FortiClient client, and is notable for its ease of use thanks to an intuitive graphical interface. However, Linux users have additional alternatives, such as using the console and integrating with the system’s network connections, each with its own advantages and disadvantages. Overall, it is a versatile tool that adapts to different user needs and preferences, with configuration methods that balance ease of use and technical flexibility.
