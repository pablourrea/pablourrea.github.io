"The following component(s) are required to run this program:" on Steam Deck LCD / OLED or Linux with Proton and/or Wine

The other day I installed a completely lawful and paid game on my Steam Deck, in another article I will talk about which methods are the best or most comfortable to install depending on the origin and the size that occupy the games, on this occasion, going one step ahead, when running/opening/running the game I found the following error:

 

To facilitate the installation of these add-ons used by most video games, Steam provides them with the “Steamworks Common Redistributables” package, but how do you install them manually on the Steam Deck or Linux with Proton and/or Wine?

 

 

Installing the Swiss army knife. Assuming that the game is installed and added to Steam, the first thing to do is to install the program “Protontricks”, to do this go to Discover or the application store of your Linux distribution and search for this application:

 

 

 

Microsoft Windows outside Microsoft Windows. Protontricks allows to make many adjustments to Proton environments, but in this occasion select the options “Select the default wineprefix” > “OK” > “Install a Windows DLL or component” > “OK”. This will display a huge alphabetical list of Microsoft components for Windows applications, you will need to search for the component you need, although for Microsoft Visual C++ Runtime there are many similar ones, the correct component is the following (You must substitute XX for the year closest to the current year):

Package Title Publisher
vcrun20XX Visual C++ 2015-20XX libraries (concrt140.dll,mfc140.dll,mfc140chs.dll,mfc140cht.dll,mfc140deu. ... Microsoft

You can select as many components as you need or want to install and continue with “OK”. This will start the installation process of all the selected components (Some like Microsoft Visual C++ Runtime will require two component installation processes) launching the necessary installation windows. In this example Microsoft Visual C++ Runtime will require you to accept the terms and conditions (Optional reading) and click “Install”, wait for it to install and then click “Close” to continue to the next component installer or end the process.

Once the process is finished it will return to the initial screen, which you can close if you do not need anything else from Protontricks. And that's it, now when you run the game it will not show the Microsoft component error.

 

 

Also in Heroic Games Launcher. If you experience the Microsoft components error in a game installed via Heroic Games Launcher, you can perform the above process in the settings by simply looking for “Winetricks” in the game settings within the launcher.
