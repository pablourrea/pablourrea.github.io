Visual Studio Code extensions for PHP and Drupal development

Visual Studio Code

Drupal

As I continue to complete developments and diversify the technologies I work with, I realize that the extensions I have installed in Visual Studio Code proliferate to optimize my time in one way or another. I don't even remember the first time I installed Microsoft's code editor, but the main advantage I saw then was its price: free, and since then I haven't used another because I'm already used to Visual Studio Code. I have to admit that at the beginning of my career I was unaware of the existence of the editor's extensions (which also have the advantage in their price as most of them are free, at least for installing them), but after some experience in PHP and Drupal, I would like to share in no particular order a small list of Visual Studio Code extensions that are key in development with these technologies.

 

 

 Drupal by Stanislav Romanov

The Drupal extension offers a comprehensive set of tools for development in this popular CMS. It facilitates programming in Drupal projects, providing syntax highlighting, hook completion, Twig and services completion, as well as global variables, complying with Drupal's programming standards through phpcs and phpcbf. It also offers the ability to search the Drupal API documentation, autocomplete translations in PHP, Twig, and JavaScript files, validation and autocompletion for YAML files, and analysis with PHPStan, although this last functionality is experimental. This tool is essential for Drupal developers looking to improve their workflow in Visual Studio Code, ensuring more efficient development with fewer errors.

 

 Drupal Smart Snippets by Andy Blum

The extension provides comprehensive support for Drupal development, offering contextual code snippets and intelligent features to streamline the coding process. These snippets are built from the core of Drupal, encompassing both hooks and form and render elements. The extension is a successor to Drupal 8 Snippets and employs advanced techniques such as automatic hook and element replacement based on the current file's name, as well as automatic generation of additional properties for form elements from documentation. Additionally, smart snippets for services allow easy access to core Drupal services with IntelliSense suggestions. Installation is straightforward through the Visual Studio Code extensions menu, and the extension is regularly updated to ensure compatibility with the latest Drupal versions. This extension significantly enhances the productivity of Drupal developers by providing a more efficient and precise coding experience in Visual Studio Code.

 

 PHP Intelephense by Ben Mewburn   (Official Extension)

The PHP Intelephense extension offers powerful code processing for PHP development, with a range of essential features that enhance productivity. It provides rapid code completion for symbols and keywords both in the current document and throughout the workspace, with automatic inclusion of use statements. Additionally, it offers detailed signature help for constructors, methods, and functions, as well as support for quickly navigating to definition and finding all references within the workspace. It also provides advanced static analysis with multiple diagnostics for open files, PSR-12 compatible formatting, built-in intelligence for HTML, JavaScript, and CSS, and highlighting of references and keywords. The extension also features an advanced PHPDoc type system, support for PHPStorm metadata, and additional functions such as symbol renaming and code folding. Some premium features are available for purchase, such as automatic PHPDoc generation, smart syntax tree tracking, and useful code actions. In summary, the extension is an essential tool for PHP developers looking to enhance their workflow in Visual Studio Code.

 

 Twig Language 2 by mblode

The Twig Language 2 extension provides comprehensive support for Twig templating in Visual Studio Code, enhancing the coding experience for Drupal developers and other users working with Twig. It offers syntax highlighting for Twig code embedded in HTML, CSS, JavaScript, and other languages, with intelligent code completion and suggestions for Twig tags, filters, and functions. Additionally, it provides detailed syntax validation and error checking, with support for advanced Twig constructs such as macros and blocks. The extension also offers useful features such as customizable snippets, bracket matching, and automatic indentation. Installation is straightforward through the Visual Studio Code extensions menu, and the extension is regularly updated to ensure compatibility with the latest Twig and Visual Studio Code versions. Overall, the extension significantly improves the Twig templating workflow in Visual Studio Code, making it an essential tool for Drupal developers and other users working with Twig.

 

 YAML by Red Hat   (Official Extension)

This extension provides robust support for the YAML language, including built-in support for Kubernetes syntax. It offers several useful features such as YAML validation, document outline schema, autocompletion, hover information support over a node, and code formatting. The extension also allows associating JSON schemas to YAML files to enhance validation and coding experience. This extension is particularly useful for developers working with YAML files, especially in Kubernetes environments.

 

 Drupal Syntax Highlighting by Marco Stazi

The Drupal Syntax Highlighting extension provides syntax highlighting support for specific Drupal file types such as .module, .inc, .theme, etc. This extension simplifies the process of setting up syntax highlighting rules for Drupal files by providing a ready-to-use solution. Instead of manually adding file types to your settings.json file. This extension is useful for Drupal developers who want their code to be highlighted and formatted correctly within Visual Studio Code. It supports various Drupal file extensions, including .module, .inc, .theme, .install, .make, .profile, .test, and .info.

 

 DDEV Manager by Biati Digital   (Official Extension)

This extension simplifies DDEV project management by providing a centralized and easy-to-use interface in Visual Studio Code. With this tool, you can visualize all your DDEV projects from the sidebar, making it easy to customize each project. Additionally, you can control your project from the sidebar or using the command menu, allowing you to easily switch PHP and NodeJS versions used in your project, as well as manage DDEV services, add or remove services, and quickly access SSH terminals for your running projects. With additional features such as one-click project creation, database snapshot management, configuration file editing, and XDebug enabling/disabling, among others, the extension provides a comprehensive solution for your DDEV development needs. It also offers configuration options that can be found in Visual Studio Code settings and is under constant development, ensuring new features and continuous improvements for an even more efficient development experience.

 

 Drupal 8 JavaScript Snippets by tsega

The extension offers useful code snippets in JavaScript extracted from the general documentation of the JavaScript API for Drupal 8. These snippets include a jQuery wrapper and Drupal 8 behavior, facilitating JavaScript development within Drupal projects. You can access the snippets through the Visual Studio Code command line or by typing the snippet prefixes directly into the code editor window. The snippets are designed to enhance productivity by providing quick access to commonly used JavaScript patterns in Drupal 8 development. Additionally, they are available only in .js extension files. This extension aims to streamline JavaScript coding in Drupal 8 projects, making it easier for developers to implement common functionalities and behaviors.

 

 Drupal 8 Twig Snippets by tsega

This extension adds useful Twig code snippets that can be used with Drupal 8. You can access the snippets through the Visual Studio Code command line or by typing the snippet prefixes directly into the code editor window. The snippets are designed to enhance productivity by providing quick access to commonly used Twig functions in Drupal 8 theme development. Additionally, they are available only in .twig extension files. This extension aims to streamline Twig programming in Drupal 8 projects, making it easier for developers to implement common functionalities and logic in templates.

 

 Composer by Ioannis Kappas

This extension provides an interface for the Composer dependency manager in PHP. It also offers schema validation for composer.json configuration files and provides a variety of Composer-compatible commands, such as dependency installation, package updating, autoloader file creation, and more. Additionally, you can customize the extension's settings to enable or disable specific features and define custom working paths.

 

 phpstan by SanderRonde   (Official Extension)

The phpstan extension provides an integrated error provider for PHPStan. It runs automatically on your code and highlights errors as you type, in addition to performing analysis across the project and displaying all errors in the Diagnose tab. It also shows variable values according to PHPStan when hovering over them, if the phpstan.enableLanguageServer setting is enabled. You can configure various options, such as the path to the configuration file, the path to your PHP project's root directory, the path to the PHPStan binary, and more. Additionally, you can adjust memory limit, full project timeout, individual file timeout, and other settings. The extension also allows customization of the display, such as enabling or disabling checking on save, showing a progress bar, and enabling the language server to provide information when hovering over code.

 

 gettext by MrOrz

The extension provides support for language files in PO (Portable Object), POT (Template PO), and POTX (Compressed Template PO) formats. It adds syntax highlighting to these files, making them easier to read and edit. Additionally, it displays useful information in the status bar, such as the total number of texts, untranslated texts, and fuzzy texts using the msgfmt --statistics command. It also includes useful keyboard shortcuts for navigating messages, such as moving focus to the next untranslated or fuzzy message, and to the previous one. This extension is useful for developers working with gettext language files (.po) and need an integrated tool to assist in editing and managing these files.

 

 gettext-duplicate-error by ovcharik

This extension highlights duplicate message definitions in .po files of gettext. This is useful for identifying and correcting errors in translation files, as having duplicate messages in a .po file can be problematic. The extension provides a helpful tool for ensuring consistency and accuracy in gettext language files (.po).

 

 PHP Debug by Xdebug   (Official Extension)

This extension provides support for debugging PHP code with Xdebug. This makes it easier to detect and correct errors in PHP code by allowing you to set breakpoints, inspect variables, trace program flow, and more. The extension acts as a debugging adapter between Visual Studio Code and Xdebug, which is a PHP extension that needs to be installed on your server. The extension supports a variety of debugging features, such as breakpoints, code stepping, stack tracing, scoped variables, user-defined constants, debug console, watchers, CLI execution, and more. It also offers support for remote debugging on remote hosts and DBGp proxy for multi-user environments. In summary, this extension makes debugging PHP code in Visual Studio Code easier and more efficient by providing powerful tools and features for detecting and fixing issues in your PHP code.

 

 phpfmt - PHP formatter by kokororin

The extension integrates phpfmt into the development environment, allowing formatting of PHP code according to standards like PSR1, PSR2, and WP, with options to customize indentation, automatically detect type and size of it, and execute PHP. With features like auto-formatting on save, specific rule configuration, and a list of available transformations, it offers a convenient way to maintain consistent and readable coding style in your projects.

 

 PHP DocBlocker by Neil Brayfield

The PHP DocBlocker extension provides a simple and dependency-free way to generate documentation blocks in PHP. It allows auto-completion of documentation blocks when typing /** above a class, function, or class property, as well as insertion of tags like @param, @return, and @throws. Additionally, it can automatically infer parameter and return types from function signatures. The extension also offers configuration options to customize documentation block templates and adjust space between description and tags, among other aspects. With support for different documentation tags and the ability to configure documentation templates according to your needs, this extension simplifies the task of generating consistent and readable documentation in your PHP projects.

 

 php cs fixer by junstyle

This extension provides a tool for formatting PHP code and improving its readability. It allows automatically fixing the format of a PHP file using the php-cs-fixer: fix this file command from the command palette or the keyboard shortcut alt+shift+f. It also offers the option to format whole documents or specific selections from the right-click context menu. The extension can be configured according to your preferences, such as the php-cs-fixer executable, formatting rules to apply, and automatic activation on saving the file. Additionally, it provides the ability to automatically install php-cs-fixer or use an existing .phar file. This extension simplifies the formatting process and enhances the consistency of PHP code in your projects.

 

 PHP Namespace Resolver by Mehedi Hassan

The PHP Namespace Resolver extension makes it easy to import and expand namespaces in PHP code. You can import specific classes or all at once, expand imported classes, sort imports by line length or alphabetically, and highlight classes that are not imported or not used. You can also automatically generate the namespace for a file. The extension offers a range of commands that you can search for in the command palette, and you can customize default settings according to your needs, such as excluding global patterns when searching for files, displaying messages in the status bar instead of in a popup window, and automatically sorting imports on saving the file. Additionally, you can assign custom key combinations to quickly access extension commands.

 

 

In summary, these extensions not only make my work easier and more efficient in Drupal or PHP projects but also demonstrate the power and versatility of Visual Studio Code as a development platform and code editor.
