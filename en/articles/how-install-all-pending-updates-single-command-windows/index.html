How to install all pending updates with a single command in Windows?

Windows
Updates

Windows Package Manager (WinGet) (Source: Wikipedia)

Pablo Urrea

4 minutes reading
Published
07/02/2025

Since computers appeared in my daily life, I have to admit that I have polarized pending updates to either black or white, meaning I either checked and installed pending updates almost daily or I did it almost never. It's true that on mobile devices, it's more convenient to update all apps from the update view in the App Store or Play Store; in Linux, you can update with an apt-get command; but in Windows, I’ve always opened each third-party application one by one to check for updates. But, what if I told you that there is a command in Windows to install all pending updates for installed programs on the system?

 

CMD, Windows' greatest ally. First, you need to access the system's CMD console as an administrator. To do so, press the “Windows 🪟” and type “CMD”. The Command Prompt will appear. To run it as an administrator, simply right-click and select “Run as administrator”. After confirming its execution as an administrator, the CMD console will open in a new window.

 

WinGet to control them all. To check which programs have a pending update to download and install, you need to run the Windows Package Manager (WinGet for friends):

winget upgrade

This command will return a table with information about the pending updates.

 

To update a single package from this list, simply run the same command followed by the ID of the program you want to update:

winget upgrade <id>

 

There is also an option to update the entire list with the --all parameter after the command:

winget upgrade --all

This will take a moment depending on the number of updates available to download and install, and will open update windows depending on each program.

 

If a program has an unchecked update, meaning the system is not yet aware of the pending update, you can search for updates for a program with the search command followed by the ID:

winget search <id>

 

It is important to note that WinGet supports the following direct installer formats; any other format or additional steps will require manual actions:

.exe .zip .inno .nsi .msi .wixproj .appx .msix

 

 

Conclusion. Although some updates may still require your attention and you may need to open the programs, most of them are downloaded and installed automatically without any issues, so in the end, WinGet is a very useful tool for automating this maintenance task in Windows. If you need more information about WinGet, you can run winget --help in the console or visit Use the WinGet tool to install and manage applications.
