Compile, compress, and improve the compatibility of JavaScript files with Babel

NodeJS
JavaScript
Babel

Pablo Urrea

7 minutes reading
Published
06/07/2024

In the article Automatic Web Styles Optimization and Compilation with SASS I talk about CSS file compilation and compression and how reducing file transfer rates impacts web performance. Unlike CSS files, JavaScript files offer more compression possibilities, and their compilation improves compatibility across different browser versions.

 

Getting Started. The first step is to install Node, the primary executor of Babel. It’s best to follow the steps on the official Node page for your required environment: https://nodejs.org/en/download/package-manager.

Now that Node is working correctly on the machine (or should be), it's time to install Babel in the project. In the official documentation, it is recommended to save all packages in the development section with the --save-dev parameter, but I'll leave that decision up to you (don't forget to run the Node project initiation command npm init first):

npm install @babel/core
npm install @babel/preset-env

And if you want to compress JavaScript files, I recommend installing the compression package:

npm install babel-preset-minify

 

Basic Configuration. Babel works with environments called "presets". You can create your own, but it's more convenient to use a published one. Among the previously installed packages are the basic Babel preset (@babel/preset-env) and the compression preset (babel-preset-minify). The Babel configuration file should be (or is usually) named babel.config.json, and it should have the following minimum structure:

{
 "targets": "",
 "presets": [],
 "plugins": []
}

The targets element is a string or an array of strings referring to browser compatibility. Its configuration is as simple as including, for example, "last 3 versions" so that the JavaScript code is compiled with compatibility for the last 3 versions of all browsers (this element is actually requests to the API browserslist-compatible of caveats). It’s not a mandatory element, but it simplifies your first steps with Babel; the presets element is an array of strings indicating the presets you will use during the compilation process. With the previously installed ones, the value of this element should be:

{
 "presets": [
   "@babel/preset-env",
   "minify"
 ],
}

And finally, the plugins element. This array of strings contains all the community Babel plug-ins or add-ons that will be used during the compilation process. Plug-ins are very useful for extending Babel's functionality, and this public repository collects many of them.

In the end, you should have a babel.config.json file that looks like this:

{
 "targets": "last 3 versions",
 "presets": [
   "@babel/preset-env",
   "minify"
 ],
 "plugins": []
}

 

Testing the Setup. To run Babel, there are countless parameters you'll find in the documentation, but the most relevant for starting is knowing that by default it requires a path to the JavaScript directory or file, and if you don't want to mess up your wonderful code, I recommend using the --out-dir parameter with an output directory:

npx babel path/to/js/directory --out-dir path/to/output/js/directory

But it's best to see it with a real example, using the above configuration file and the following JavaScript code:

// Function to change the text of an element.
function changeText() {
   document.getElementById("demo-text").innerText = "Text changed!";
}
// Function to show an alert.
function showAlert() {
   alert("Hello! This is an alert.");
}
// Function to add two numbers and print the result in the DOM.
function sumNumbers() {
   let num1 = parseInt(document.getElementById("num1").value);
   let num2 = parseInt(document.getElementById("num2").value);
   let sum = num1 + num2;
   document.getElementById("result").innerText = "The sum is: " + sum;
}
// Event to change the body background color.
function changeBackgroundColor() {
   document.body.style.backgroundColor = "#f0f0f0";
}
// Add events to buttons when the page loads.
window.onload = function() {
   document.getElementById("change-text-btn").addEventListener("click", changeText);
   document.getElementById("alert-btn").addEventListener("click", showAlert);
   document.getElementById("sum-btn").addEventListener("click", sumNumbers);
   document.getElementById("change-bg-btn").addEventListener("click", changeBackgroundColor);
}

This takes up 1.1 KiB, but after compiling it with Babel, this is the result:

"use strict";// Function to change the text of an element.
function changeText(){document.getElementById("demo-text").innerText="Text changed!"}// Function to show an alert.
function showAlert(){alert("Hello! This is an alert.")}// Function to add two numbers and print the result in the DOM.
function sumNumbers(){var a=parseInt(document.getElementById("num1").value),b=parseInt(document.getElementById("num2").value);document.getElementById("result").innerText="The sum is: "+(a+b)}// Event to change the body background color.
function changeBackgroundColor(){document.body.style.backgroundColor="#f0f0f0"}// Add events to buttons when the page loads.
window.onload=function(){document.getElementById("change-text-btn").addEventListener("click",changeText),document.getElementById("alert-btn").addEventListener("click",showAlert),document.getElementById("sum-btn").addEventListener("click",sumNumbers),document.getElementById("change-bg-btn").addEventListener("click",changeBackgroundColor)};

This size is 1.09 KiB, which can be reduced much more by using plug-ins.

 

Essential Plug-ins. The use of plug-ins in Babel enhances the base package to the point of being unrecognizable. Some of the plug-ins I recommend are the following:

  •  ➡ minify-replace
  •  ➡ minify-simplify
  •  ➡ minify-infinity
  •  ➡ minify-builtins
  •  ➡ minify-numeric-literals
  •  ➡ minify-flip-comparisons
  •  ➡ minify-constant-folding
  •  ➡ minify-type-constructors
  •  ➡ transform-minify-booleans
  •  ➡ minify-guarded-expressions
  •  ➡ transform-regexp-constructors
  •  ➡ transform-merge-sibling-variables
  •  ➡ transform-inline-consecutive-adds
  •  ➡ transform-simplify-comparison-operators
  •  ➡ babel-plugin-transform-remove-undefined
  •  ➡ @babel/plugin-transform-member-expression-literals

 

Conclusion. The automatic compilation and optimization of JavaScript with Babel is an essential practice for improving web page performance. By significantly reducing file sizes, the file transfer rate is also reduced. This not only speeds up loading times but also maintains a high standard of quality and performance in projects and provides a smoother user experience across a variety of environments and devices.
