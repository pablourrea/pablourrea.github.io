Building and exporting a static website with decoupled Drupal and Tome

Drupal
Decoupled Drupal

Pablo Urrea

Published
04/03/2024

You might wonder, why choose Drupal for a static site when there are other more specific options available? Well, Drupal is known for its robustness and its ability to effectively handle complex projects. With Tome's help, we can transform a dynamic Drupal website into a static, easily distributable, and quickly loadable version. This is ideal for websites that don't require frequent updates and can benefit from the speed and security of static sites. In the ever-evolving world of web development, creating static sites has become a popular choice due to its performance, security, and ease of implementation.


Decoupled Drupal and Tome. Decoupled Drupal is an architecture that separates the presentation layer (front-end) from the logic and data (back-end). This means that Drupal is used only as a content management system and is not directly linked to the user interface. On the other hand, Tome is a tool that allows exporting Drupal websites as static HTML files, making them independent of a back-end server.


Setting up a site with Decoupled Drupal. Start by installing Drupal in the traditional way. You can download Drupal files from its official website and follow the installation instructions (Old school, let's go), although you can install it in a way that suits you best. Once Drupal is installed, configure your content and structure as you wish. This may include creating content, configuring content types, and building views.

 

Implementing Tome. Use Composer to install the Tome library in your Drupal project. This can be done by running the following command in the command line:

composer require drupal/tome

Once the Tome library is installed and the Drupal module is enabled, you can generate the static files of your Drupal website by running the following command:

drush tome:export

This command will generate a static version of your Drupal site in a specified folder.


Implementation and deployment. Set up a web server to serve the static files generated by Tome. You can use any web server that supports static files, such as Apache, Nginx, or even GitHub Pages. Copy the static files generated by Tome into the root directory of your web server. Once this is done, your decoupled Drupal website will be available at your server's URL.


Benefits of a static website with Drupal and Tome. A static website created with Drupal and Tome offers several significant benefits. Firstly, it notably improves the site's performance by loading faster, as it eliminates the need for server-side processing. Additionally, it provides an additional layer of security by reducing potential vulnerability points by removing server logic. Lastly, it simplifies the deployment process by generating static files with Tome, thus eliminating the need to rely on a back-end server. This combination offers a powerful and flexible solution for creating high-performance static websites.

 

 

For more information, you can consult the Tome documentation.
