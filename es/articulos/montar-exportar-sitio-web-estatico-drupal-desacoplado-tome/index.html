Montar y exportar un sitio web estático con Drupal desacoplado y Tome

Drupal
Drupal Desacoplado

Logo de Tome

Pablo Urrea

Lectura de 5 minutos
Publicado
04/03/2024

Puede que te preguntes, ¿por qué elegir Drupal para un sitio estático cuando hay otras opciones más específicas disponibles? Bueno, Drupal es conocido por su robustez y su capacidad para manejar proyectos complejos de manera efectiva. Con la ayuda de Tome, podemos transformar un sitio web dinámico de Drupal en una versión estática, fácilmente distribuible y rápidamente cargable. Esto es ideal para sitios web que no necesitan actualizaciones frecuentes y pueden beneficiarse de la velocidad y la seguridad de los sitios estáticos. En el mundo en constante evolución del desarrollo web, la creación de sitios estáticos se ha convertido en una opción popular debido a su rendimiento, seguridad y facilidad de implementación.


Drupal desacoplado y Tome. Drupal desacoplado es una arquitectura que separa la capa de presentación (front-end) de la lógica y los datos (back-end). Esto significa que Drupal se utiliza solo como un sistema de gestión de contenido y no está vinculado directamente a la interfaz de usuario. Por otro lado, Tome es una herramienta que permite exportar sitios web Drupal como archivos HTML estáticos, lo que los hace independientes de un servidor de back-end.


Configuración de un sitio web con Drupal desacoplado. Comienza instalando Drupal de la manera tradicional. Puedes hacerlo descargando los archivos de Drupal desde su sitio web oficial y siguiendo las instrucciones de instalación (A la antigua, vamos), aunque puedes instalarlo de la manera que te resulte más cómodo. Una vez que Drupal esté instalado, configura tu contenido y estructura de la manera que desees. Esto puede incluir la creación de contenido, la configuración de tipos de contenido y la construcción de vistas.

 

Implementación de Tome. Utiliza Composer para instalar la biblioteca Tome en tu proyecto de Drupal. Esto se puede hacer ejecutando el siguiente comando en la línea de comandos:

composer require drupal/tome

Una vez instalada la biblioteca Tome y habilitado el módulo de Drupal, puedes generar los archivos estáticos de tu sitio web Drupal ejecutando el siguiente comando:

drush tome:export

Este comando generará una versión estática de tu sitio Drupal en una carpeta especificada.


Implementación y despliegue. Configura un servidor web para servir los archivos estáticos generados por Tome. Puedes utilizar cualquier servidor web que admita archivos estáticos, como Apache, Nginx o incluso GitHub Pages. Copia los archivos estáticos generados por Tome en el directorio raíz de tu servidor web. Una vez hecho esto, tu sitio web Drupal desacoplado estará disponible en la dirección URL de tu servidor.


Beneficios de un sitio web estático con Drupal y Tome. Un sitio web estático creado con Drupal y Tome ofrece una serie de beneficios significativos. En primer lugar, mejora notablemente el rendimiento del sitio al cargar más rápidamente, ya que elimina la necesidad de procesamiento en el servidor. Además, proporciona una capa adicional de seguridad al reducir los puntos de vulnerabilidad potenciales al eliminar la lógica del servidor. Por último, simplifica el proceso de implementación al generar archivos estáticos con Tome, eliminando así la necesidad de depender de un servidor de back-end. Esta combinación ofrece una solución potente y flexible para la creación de sitios web estáticos de alto rendimiento.

 

 

Para más información puedes consultar la documentación de Tome.
