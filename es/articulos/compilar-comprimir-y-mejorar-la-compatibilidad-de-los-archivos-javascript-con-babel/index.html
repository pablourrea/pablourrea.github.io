Compilar, comprimir y mejorar la compatibilidad de los archivos JavaScript con Babel

NodeJS
JavaScript
Babel

Pablo Urrea

Lectura de 7 minutos
Publicado
02/07/2024

En el artículo Optimización Y Compilación Automática De Estilos Web Con SASS hablo sobre compilación y compresión de archivos CSS y lo que supone en el rendimiento de una web reducir la tasa de transferencia de archivos. A diferencia de los CSS, los archivos de JavaScript ofrecen más posibilidades de compresión, y la compilación de estos mejora la compatibilidad entre diferentes versiones de navegadores.

 

Primeros pasos. Lo primero de todo es instalar Node, el ejecutor principal de Babel, para ello lo mejor es seguir los pasos de la página oficial de Node para el entorno en el que necesites: https://nodejs.org/en/download/package-manager.

Ahora que Node funciona correctamente en la máquina (O debería), es el momento de instalar Babel en el proyecto, en la documentación oficial recomiendan guardar todos los paquetes en la sección de desarrollo con el parámetro --save-dev, pero esto lo dejo bajo tu decisión (No olvides ejecutar antes el comando de iniciación de proyecto de Node npm init):

npm install @babel/core
npm install @babel/preset-env

Y si quieres comprimir los archivos de JavaScript, te recomiendo instalar el paquete de compresión:

npm install babel-preset-minify

 

Configuraciones básicas. Babel funciona con entornos llamados "presets", puedes crear uno propio, pero lo más cómodo es utilizar uno publicado, entre los paquetes anteriores está el preset básico de Babel (@babel/preset-env) y el preset de compresión (babel-preset-minify). El archivo de configuración de Babel debe llamarse (O suele llamarse) babel.config.json, y debe tener la siguiente estructura mínima:

{
 "targets": "",
 "presets": [],
 "plugins": []
}

El elemento targets es un string o array de strings que hace referencia a la compatibilidad entre navegadores, su configuración es tan sencilla como incluir, por ejemplo, "last 3 versions" para que el código JavaScript se compile con compatibilidad de las 3 últimas versiones de todos los navegadores (Este elemento es en realidad solicitudes al API browserslist-compatible de caveats), realmente no es un elemento obligatorio, pero simplifica tus primeros pasos con Babel; el elemento presets es un array de strings que indica los presets que vas a utilizar durante el proceso de compilación, con los instalados anteriormente el valor de este elemento debe ser:

{
 "presets": [
   "@babel/preset-env",
   "minify"
 ],
}

Y por último, el elemento plugins, este array de strings contiene todos los plug-ins o add-ons de la comunidad de Babel que se van a utilizar durante el proceso de compilación. Los plug-ins son muy útiles para extender la funcionalidad de Babel, este repositorio público recoge muchos de ellos.

Al final, debe quedarte un archivo babel.config.json parecido a esto:

{
 "targets": "last 3 versions",
 "presets": [
   "@babel/preset-env",
   "minify"
 ],
 "plugins": []
}

 

Probar la máquina. Para ejecutar Babel hay infinidad de parámetros que encontrarás en su documentación, pero lo más relevante para empezar es saber que por defecto requiere una ruta al directorio o archivo JavaScript, y si no quieres mancillar tu maravilloso código, te recomiendo usar el parámetro --out-dir con un directorio de salida:

npx babel ruta/al/directorio/js --out-dir ruta/al/directorio/de/salida/js

Pero lo mejor es verlo con un ejemplo real, para ello utilizaré el archivo de configuración anterior y el siguiente código JavaScript:

// Función para cambiar el texto de un elemento.
function changeText() {
   document.getElementById("demo-text").innerText = "¡Texto cambiado!";
}

// Función para mostrar una alerta.
function showAlert() {
   alert("¡Hola! Esto es una alerta.");
}

// Función para sumar dos números e imprimir el resultado en el DOM.
function sumNumbers() {
   let num1 = parseInt(document.getElementById("num1").value);
   let num2 = parseInt(document.getElementById("num2").value);
   let sum = num1 + num2;
   document.getElementById("result").innerText = "La suma es: " + sum;
}

// Evento para cambiar el color de fondo del cuerpo.
function changeBackgroundColor() {
   document.body.style.backgroundColor = "#f0f0f0";
}

// Agregar eventos a botones al cargar la página.
window.onload = function() {
   document.getElementById("change-text-btn").addEventListener("click", changeText);
   document.getElementById("alert-btn").addEventListener("click", showAlert);
   document.getElementById("sum-btn").addEventListener("click", sumNumbers);
   document.getElementById("change-bg-btn").addEventListener("click", changeBackgroundColor);
}

Este ocupa 1.1 KiB, pero después de compilarlo con Babel este es el resultado:

"use strict";// Función para cambiar el texto de un elemento.
function changeText(){document.getElementById("demo-text").innerText="\xA1Texto cambiado!"}// Función para mostrar una alerta.
function showAlert(){alert("\xA1Hola! Esto es una alerta.")}// Función para sumar dos números e imprimir el resultado en el DOM.
function sumNumbers(){var a=parseInt(document.getElementById("num1").value),b=parseInt(document.getElementById("num2").value);document.getElementById("result").innerText="La suma es: "+(a+b)}// Evento para cambiar el color de fondo del cuerpo.
function changeBackgroundColor(){document.body.style.backgroundColor="#f0f0f0"}// Agregar eventos a botones al cargar la página.
window.onload=function(){document.getElementById("change-text-btn").addEventListener("click",changeText),document.getElementById("alert-btn").addEventListener("click",showAlert),document.getElementById("sum-btn").addEventListener("click",sumNumbers),document.getElementById("change-bg-btn").addEventListener("click",changeBackgroundColor)};

El tamaño de este es de 1.09 KiB, número el cual se puede reducir mucho más mediante el uso de plug-ins.

 

Plug-ins esenciales. El uso de plug-ins en Babel mejora el paquete base hasta tal punto de ser irreconocible, algunos de los plug-ins que recomiendo son los siguientes:

  •  ➡ minify-replace
  •  ➡ minify-simplify
  •  ➡ minify-infinity
  •  ➡ minify-builtins
  •  ➡ minify-numeric-literals
  •  ➡ minify-flip-comparisons
  •  ➡ minify-constant-folding
  •  ➡ minify-type-constructors
  •  ➡ transform-minify-booleans
  •  ➡ minify-guarded-expressions
  •  ➡ transform-regexp-constructors
  •  ➡ transform-merge-sibling-variables
  •  ➡ transform-inline-consecutive-adds
  •  ➡ transform-simplify-comparison-operators
  •  ➡ babel-plugin-transform-remove-undefined
  •  ➡ @babel/plugin-transform-member-expression-literals

 

Conclusión. La compilación y optimización automática de JavaScript con Babel, es una práctica esencial para mejorar el rendimiento de las páginas web. Al reducir significativamente el tamaño de los archivos, se reduce también la tasa de transferencia de archivos, esto no solo acelera el tiempo de carga, sino que también mantiene un alto estándar de calidad y rendimiento en los proyectos y proporciona una experiencia de usuario más fluida en una variedad de entornos y dispositivos.
