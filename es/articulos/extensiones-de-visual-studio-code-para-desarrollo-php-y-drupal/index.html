Extensiones de Visual Studio Code para desarrollo PHP y Drupal

Publicado
01/05/2024

A medida que voy completando desarrollos y diversificando las tecnologías con las que trabajo, me doy cuenta de que las extensiones que tengo instaladas en Visual Studio Code proliferan para optimizar mi tiempo de una forma u otra. Ya ni recuerdo la primera vez que instalé el editor de código de Microsoft, pero la principal ventaja que le vi entonces era su precio: gratis, y desde entonces no he usado otro porque ya estoy acostumbrado a Visual Studio Code. Tengo que reconocer que al principio de mi carrera desconocía la existencia de las extensiones del editor (Las cuales tienen también la ventaja en su precio al ser la mayoría gratuitas, al menos para instalarlas), pero, tras cierto recorrido en PHP y Drupal, me gustaría compartir sin un orden específico una pequeña lista de extensiones de Visual Studio Code que son clave en el desarrollo con estas tecnologías.

 

 

 Drupal por Stanislav Romanov

La extensión Drupal ofrece un conjunto completo de herramientas para el desarrollo en este popular CMS. Esta facilita la programación en proyectos de Drupal, proporcionando resaltado de sintaxis, completado de hooks, Twig y servicios, además de variables globales, cumpliendo con los estándares de programación de Drupal mediante phpcs y phpcbf. También ofrece la capacidad de buscar en la documentación de la API de Drupal, autocompletar traducciones en archivos PHP, Twig y JavaScript, validación y autocompletado para archivos YAML, y análisis con PHPStan, aunque esta última funcionalidad es experimental. Esta herramienta es esencial para desarrolladores de Drupal que buscan mejorar su flujo de trabajo en Visual Studio Code, asegurando un desarrollo más eficiente y con menos errores.

 

 Drupal Smart Snippets por Andy Blum

La extensión ofrece un soporte completo para el desarrollo de Drupal, proporcionando snippets de código contextuales y funciones inteligentes para agilizar el proceso de codificación. Estos snippets están construidos a partir del núcleo de Drupal, incluyendo tanto hooks como elementos de formulario y renderización. La extensión es una sucesora de Drupal 8 Snippets y utiliza técnicas avanzadas como el reemplazo automático de hooks y elementos basado en el nombre del archivo actual, así como la generación automática de propiedades adicionales para elementos de formulario a partir de la documentación. Además, los snippets inteligentes para servicios permiten un fácil acceso a los servicios principales de Drupal con sugerencias de intellisense. La instalación es sencilla a través del menú de extensiones de Visual Studio Code, y la extensión se actualiza periódicamente para asegurar su compatibilidad con las últimas versiones de Drupal. Esta extensión mejora significativamente la productividad de los desarrolladores de Drupal al ofrecer una experiencia de codificación más eficiente y precisa en Visual Studio Code.

 

 PHP Intelephense por Ben Mewburn   (Extensión oficial)

La extensión PHP Intelephense ofrece un potente procesado de código para el desarrollo de PHP, con una serie de características esenciales que mejoran la productividad. Proporciona completado de código rápido para símbolos y palabras clave tanto en el documento actual como en todo el espacio de trabajo, con la inclusión automática de declaraciones de uso. Además, brinda ayuda detallada de firma para constructores, métodos y funciones, así como soporte para ir rápidamente a la definición y encontrar todas las referencias en el espacio de trabajo. También ofrece un análisis estático avanzado con múltiples diagnósticos para archivos abiertos, formateo compatible con PSR-12, inteligencia de código integrada para HTML, JavaScript y CSS, y resaltado de referencias y palabras clave. La extensión también cuenta con un sistema avanzado de tipos de PHPDoc, soporte para metadatos de PHPStorm, y funciones adicionales como el renombrado de símbolos y el plegado de código. Algunas características premium están disponibles para su compra, como la creación automática de PHPDoc, el seguimiento inteligente del árbol de sintaxis y acciones útiles de código. En resumen, la extensión es una herramienta esencial para los desarrolladores de PHP que buscan mejorar su flujo de trabajo en Visual Studio Code.

 

 Twig Language 2 por mblode

La extensión creada por Matthew Blode, proporciona un conjunto completo de herramientas para trabajar con archivos Twig en tus proyectos. Esta extensión incluye resaltado de sintaxis, snippets de código, soporte para Emmet y formateo de código con Pretty Diff 3. Además, ofrece información detallada sobre los elementos cuando pasas el cursor sobre ellos y agrega un conjunto útil de snippets de código para Craft CMS/Twig. Es importante destacar que esta extensión no incluye Intellisense para HTML. En resumen, esta extensión es una herramienta esencial para desarrolladores que trabajan con Twig en sus proyectos, ofreciendo una experiencia de codificación más eficiente y productiva en Visual Studio Code.

 

 YAML por Red Hat   (Extensión oficial)

Esta extensión proporciona un sólido soporte para el lenguaje YAML, incluido el soporte integrado para la sintaxis de Kubernetes. Ofrece varias características útiles, como la validación de YAML, el esquema de contorno del documento, autocompletado, soporte para mostrar información al pasar el cursor sobre un nodo, y formateo de código. La extensión también permite asociar esquemas JSON a archivos YAML para mejorar la validación y la experiencia de codificación. Esta extensión es particularmente útil para desarrolladores que trabajan con archivos YAML, especialmente en entornos de Kubernetes.

 

 Drupal Syntax Highlighting por Marco Stazi

La extensión Drupal Syntax Highlighting proporciona soporte de resaltado de sintaxis para tipos de archivos específicos de Drupal, como .module, .inc, .theme, etc. Esta extensión simplifica el proceso de configurar reglas de resaltado de sintaxis para archivos de Drupal al proporcionar una solución lista para usar. En lugar de agregar manualmente tipos de archivos a su archivo settings.json. Esta extensión es útil para desarrolladores de Drupal que desean que su código se resalte y formatee correctamente dentro de Visual Studio Code. Admite varias extensiones de archivo de Drupal, incluidas .module, .inc, .theme, .install, .make, .profile, .test y .info.

 

 DDEV Manager por Biati Digital   (Extensión oficial)

Esta extensión simplifica la gestión de proyectos DDEV al proporcionar una interfaz centralizada y fácil de usar en Visual Studio Code. Con esta herramienta, puedes visualizar todos tus proyectos DDEV desde la barra lateral, lo que facilita la personalización de cada proyecto. Además, puedes controlar tu proyecto desde la barra lateral o utilizando el menú de comandos, lo que te permite cambiar fácilmente la versión de PHP y NodeJS utilizada en tu proyecto, así como gestionar servicios DDEV, añadir o eliminar servicios y acceder rápidamente a terminales SSH para tus proyectos en ejecución. Con características adicionales como la creación de proyectos con un solo clic, la gestión de instantáneas de bases de datos, la edición de archivos de configuración y la habilitación/deshabilitación de XDebug, entre otras, la extensión proporciona una solución integral para tus necesidades de desarrollo con DDEV. Además, ofrece opciones de configuración que se pueden encontrar en la configuración de Visual Studio Code y se encuentra en constante desarrollo, lo que garantiza nuevas características y mejoras continuas para una experiencia de desarrollo aún más eficiente.

 

 Drupal 8 JavaScript Snippets por tsega

La extensión ofrece snippets de código útiles en JavaScript extraídos de la documentación general de la API de JavaScript para Drupal 8. Estos snippets incluyen un envoltorio jQuery y un comportamiento Drupal 8, facilitando el desarrollo de JavaScript dentro de proyectos Drupal. Puedes acceder a los snippets a través de la línea de comandos de Visual Studio Code o escribiendo los prefijos de los snippets directamente en la ventana del editor de código. Los snippets están diseñados para mejorar la productividad al ofrecer acceso rápido a patrones de JavaScript comúnmente utilizados en el desarrollo de Drupal 8. Además, están disponibles solo en archivos con extensión .js. Esta extensión tiene como objetivo agilizar la codificación en JavaScript en proyectos de Drupal 8, facilitando a los desarrolladores la implementación de funcionalidades y comportamientos comunes.

 

 Drupal 8 Twig Snippets por tsega

Esta extensión agrega snippets de código Twig útiles que se pueden utilizar con Drupal 8. Puedes acceder a los snippets a través de la línea de comandos de Visual Studio Code o escribiendo los prefijos de los snippets directamente en la ventana del editor de código. Los snippets están diseñados para mejorar la productividad al ofrecer acceso rápido a funciones Twig comúnmente utilizadas en el desarrollo de temas de Drupal 8. Además, están disponibles solo en archivos con extensión .twig. Esta extensión tiene como objetivo agilizar la programación en Twig en proyectos de Drupal 8, facilitando a los desarrolladores la implementación de funcionalidades y lógica común en las plantillas.

 

 Composer por Ioannis Kappas

Esta extensión proporciona una interfaz para el administrador de dependencias Composer en PHP. También ofrece validación de esquema para archivos de configuración composer.json y proporciona una variedad de comandos compatibles con Composer, como la instalación de dependencias, la actualización de paquetes, la creación de archivos de autoloader, y más. Además, puedes personalizar la configuración de la extensión para habilitar o deshabilitar características específicas y definir rutas de trabajo personalizadas.

 

 phpstan por SanderRonde   (Extensión oficial)

La extensión phpstan proporciona un proveedor de errores integrado para PHPStan. Se ejecuta automáticamente en tu código y resalta los errores a medida que escribes, además de realizar análisis en todo el proyecto y mostrar todos los errores en la pestaña de Diagnósticos. También muestra los valores de las variables según PHPStan al momento de pasar el cursor sobre ellas, si se habilita la configuración phpstan.enableLanguageServer. Puedes configurar varias opciones, como la ruta al archivo de configuración, la ruta al directorio raíz de tu proyecto PHP, la ruta al binario de PHPStan, y más. Además, puedes ajustar la memoria límite, el tiempo de espera del proyecto completo, el tiempo de espera para archivos individuales, y otras configuraciones. La extensión también permite la personalización de la visualización, como habilitar o deshabilitar la verificación al guardar, mostrar una barra de progreso, y habilitar el servidor de lenguaje para proporcionar información al pasar el cursor sobre el código.

 

 gettext por MrOrz

La extensión proporciona soporte para archivos de idioma en formato PO (Portable Object), POT (Template PO), y POTX (Compressed Template PO). Agrega resaltado de sintaxis a estos archivos, lo que facilita la lectura y edición. Además, muestra información útil en la barra de estado, como el número total de textos, textos no traducidos y textos difusos utilizando el comando msgfmt --statistics. También incluye atajos de teclado útiles para navegar por los mensajes, como mover el enfoque al siguiente mensaje no traducido o difuso, y al anterior. Esta extensión es útil para desarrolladores que trabajan con archivos de idioma gettext (.po) y necesitan una herramienta integrada para ayudar en la edición y gestión de estos archivos.

 

 gettext-duplicate-error por ovcharik

Esta extensión resalta las definiciones de mensajes duplicados en archivos .po de gettext. Esto es útil para identificar y corregir errores en los archivos de traducción, ya que puede ser problemático tener mensajes duplicados en un archivo .po. La extensión proporciona una herramienta útil para garantizar la coherencia y la precisión en los archivos de idioma gettext (.po).

 

 PHP Debug por Xdebug   (Extensión oficial)

Esta extensión proporciona soporte para depurar código PHP con Xdebug. Esto facilita la detección y corrección de errores en el código PHP al permitir establecer puntos de interrupción, inspeccionar variables, seguir el flujo del programa y mucho más. La extensión actúa como un adaptador de depuración entre Visual Studio Code y Xdebug, que es una extensión de PHP que necesita estar instalada en su servidor. La extensión admite una variedad de funciones de depuración, como puntos de interrupción, pasos de código, seguimiento de pila, variables de ámbito, constantes definidas por el usuario, consola de depuración, observadores, ejecución como CLI y más. También ofrece soporte para depuración remota en hosts remotos y proxy DBGp para entornos multiusuario. En resumen, esta extensión hace que la depuración de código PHP en Visual Studio Code sea más fácil y eficiente al proporcionar herramientas y funciones poderosas para detectar y solucionar problemas en su código PHP.

 

 phpfmt - PHP formatter por kokororin

La extensión integra phpfmt en el entorno de desarrollo, permitiendo el formateo de código PHP según estándares como PSR1, PSR2 y WP, con opciones para personalizar la sangría, la detección automática del tipo y tamaño de la misma, y la ejecución de PHP. Con características como el formateo automático al guardar, la configuración de reglas específicas y una lista de transformaciones disponibles, ofrece una manera conveniente de mantener un estilo de codificación consistente y legible en tus proyectos.

 

 PHP DocBlocker por Neil Brayfield

La extensión PHP DocBlocker proporciona una forma sencilla y libre de dependencias para generar bloques de documentación en PHP. Permite completar automáticamente los bloques de documentación al escribir /** encima de una clase, función o propiedad de clase, así como la inserción de etiquetas como @param, @return, y @throws. Además, puede inferir automáticamente los tipos de parámetros y de retorno a partir de las firmas de las funciones. La extensión también ofrece opciones de configuración para personalizar las plantillas de los bloques de documentación y ajustar el espacio entre la descripción y las etiquetas, entre otros aspectos. Con soporte para diferentes etiquetas de documentación y la capacidad de configurar las plantillas de documentación según tus necesidades, esta extensión simplifica la tarea de generar documentación coherente y legible en tus proyectos de PHP.

 

 php cs fixer por junstyle

Esta extensión proporciona una herramienta para formatear código PHP y mejorar su legibilidad. Permite corregir automáticamente el formato de un archivo PHP utilizando el comando php-cs-fixer: fix this file desde la paleta de comandos o el atajo de teclado alt+shift+f. También ofrece la opción de formatear documentos o selecciones específicas desde el menú contextual del botón derecho del mouse. La extensión se puede configurar según tus preferencias, como el ejecutable de php-cs-fixer, las reglas de formato a aplicar y la activación automática al guardar el archivo. Además, proporciona la capacidad de instalar php-cs-fixer automáticamente o utilizar un archivo .phar existente. Esta extensión simplifica el proceso de formateo y mejora la consistencia del código PHP en tus proyectos.

 

 PHP Namespace Resolver por Mehedi Hassan

La extensión PHP Namespace Resolver facilita la importación y expansión de espacios de nombres en código PHP. Puedes importar clases específicas o todas a la vez, expandir clases importadas, ordenar las importaciones por longitud de línea o en orden alfabético, y resaltar clases que no están importadas o no se utilizan. También puedes generar automáticamente el espacio de nombres para un archivo. La extensión ofrece una serie de comandos que puedes buscar en la paleta de comandos, y puedes personalizar los ajustes predeterminados según tus necesidades, como la exclusión de patrones globales al buscar archivos, mostrar mensajes en la barra de estado en lugar de en una ventana emergente, y ordenar automáticamente las importaciones al guardar el archivo. Además, puedes asignar combinaciones de teclas personalizadas para acceder rápidamente a los comandos de la extensión.

 

 

En resumen, estas extensiones no solo hacen que mi trabajo sea más fácil y eficiente en proyectos de Drupal o PHP, sino que también demuestran el poder y la versatilidad de Visual Studio Code como una plataforma de desarrollo y editor de código.
