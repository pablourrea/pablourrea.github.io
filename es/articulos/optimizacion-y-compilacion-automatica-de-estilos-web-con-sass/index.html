Optimización y compilación automática de estilos web con SASS

NodeJS
SASS
CSS

Logo de SASS

Pablo Urrea

Lectura de 10 minutos
Publicado
30/06/2024

SASS (Syntactically Awesome Style Sheets) o Super CSS para los amigos (SIUUUUUUUSS en potugués), permite compilar de manera automática el desarrollo de estilos por componentes para la creación de temas web. Este sistema resulta bastante útil para unificar el archivo de CSS de una página web para reducir la transferencia de archivos y mejorar el rendimiento (Un paso más cerca de que Google Lighthouse le dé a tu página una puntuación 100/100).

 

Rápido, fácil, y para toda la familia. Lo primero de todo es instalar Node, el ejecutor principal de SASS, para ello lo mejor es seguir los pasos de la página oficial de Node para el entorno en el que necesites: https://nodejs.org/en/download/package-manager.

Ahora que Node funciona correctamente en la máquina (O debería), es el momento de instalar SASS, puedes instalarlo globalmente en toda la máquina (recomendado para pruebas) como recomiendan en la documentación oficial de SASS:

npm install -g sass

O puedes instalar SASS en el proyecto en el cual vas a utilizar el paquete desde la carpeta raíz del paquete (No olvides ejecutar antes el comando de iniciación de proyecto de Node npm init):

npm install sass

 

El tiempo de ejecución es menor al esperado. Compilar el archivo es bastante sencillo, el comando sass acepta diversos parámetros, pero los más útiles (probablemente) son la ruta de entrada SCSS, la ruta de salida CSS, el parámetro de estilos style para compilar los estilos expandidos o comprimidos (expanded (Por defecto) o compressed), y el parámetro watch para que se compile automáticamente cada vez que detecta un cambio guardado en los archivos SCSS. Un ejemplo de como queda el comando con estos parámetros aplicados es:

npx sass --watch --style=compressed ruta/al/archivo.scss:ruta/al/archivo.css

En este ejemplo se le ha indicado a SASS que compile de forma comprimida el archivo principal SCSS (Ese que suele contener todas las dependencias) y que compile el resultado comprimido en el archivo CSS de la ruta especificada. Si necesitas más configuraciones, esta es la salida de sass --help:

En un ejemplo real, pongamos el siguiente archivo CSS sin optimizar con SASS:

body {
  font: Helvetica, sans-serif;
  color: #333;
}

Este ocupa 54 bytes, y de ser necesario añadir más estilos con el mismo color o fuente, habría que realizar una copia del mismo estilo, lo cual es engorroso para el desarrollador.

Ahora bien, convierto este archivo CSS a SCSS:

$font-stack: Helvetica, sans-serif;
$primary-color: #333;

body {
 font: $font-stack;
 color: $primary-color;
}

Y al compilarlo con compresión este es el resultado:

body{font:Helvetica,sans-serif;color:#333}

Ocupa 43 bytes, y el desarrollador no se tiene que molestar en descomprimirlo para editarlo, porque los estilos se configuran desde el archivo SCSS.

 

En los ejemplos anteriores, la diferencia de tamaño puede no parecer demasiada, pero al escalarlo a proyectos más grandes, la diferencia se vuelve considerable y la comodidad del uso de variables se vuelve más necesaria.

Otro ejemplo de las ventajas de SASS es el anidamiento de elementos, pudiendo anidar bajo un mismo paraguas padre varios elementos hijos, el siguiente archivo CSS tiene muchos anidamientos que en el momento del desarrollo pueden resultar confusos e inducir a error, dejando de funcionar los estilos porque no reconoce correctamente el elemento que se desea seleccionar:

body element.class__one#id-element .class__one__two {
 font: $font-stack;
 color: $primary-color;
}

Al convertirlo a SASS se observa que los anidamientos mejoran la legibilidad de los estilos:

$font-stack: Helvetica, sans-serif;
$primary-color: #333;

body {
  element {
    &.class {
      &__one {
        &#id-element {
          .class {
            &__two {
              font: $font-stack;
              color: $primary-color;
            }
          }
        }
      }
    }
  }
}

 

 

Conclusión. Estos ejemplos son solo la punta del iceberg que hace que SASS mejore el desarrollo de estilos. Lo mejor es leer la documentación oficial de SASS para ver todas las posibilidades de la herramienta, donde también disponen de un compilador online para que puedas hacer pruebas con el código CSS antes de migrar tu proyecto.
