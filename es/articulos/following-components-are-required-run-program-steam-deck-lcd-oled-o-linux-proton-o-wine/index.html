"The following component(s) are required to run this program:" en Steam Deck LCD / OLED o Linux con Proton y/o Wine

El otro día instalé un juego completamente lícito y pagado en mi Steam Deck, en otro artículo hablaré de qué métodos son los mejores o más cómodos para instalar dependiendo del origen y el tamaño que ocupan los juegos, en esta ocasión, yendo un paso adelante, al ejecutar/abrir/correr el juego me encontré el siguiente error:

 

Una traducción cutre al español es “Se necesita(n) el/los siguiente(s) componente(s) para ejecutar este programa:” y luego indica que el error proviene del típico driver, controlador o programa de terceros Microsoft Visual C++ Runtime, pero que perfectamente podría ser cualquier otro componente de Microsoft. Para facilitar la instalación de estos complementos que utilizan la mayoría de videojuegos, Steam los proporciona con el paquete “Redistribuibles comunes de Steamworks”, pero ¿Cómo se instalan manualmente en la Steam Deck o Linux con Proton y/o Wine?

 

 

Instalando la navaja suiza. Dando por hecho que el juego está instalado y agregado a Steam, lo primero que hay que hacer es instalar el programa “Protontricks”, para ello accede a Discover o la tienda de aplicaciones de tu distribución de Linux y busca esta aplicación:

 

 

 

Microsoft Windows fuera de Microsoft Windows. Protontricks permite realizar muchos ajustes a entornos de Proton, pero en esta ocasión selecciona las opciones “Select the default wineprefix” > “OK” > “Install a Windows DLL or component” > “OK”. Esto desplegará una enorme lista ordenada alfabéticamente de componentes de Microsoft para aplicaciones de Windows, será necesario que busques el componente que necesitas, aunque para Microsoft Visual C++ Runtime hay muchos similares, el componente correcto es el siguiente (Debes sustituir XX por el año más cercano al año actual):

Package Title Publisher
vcrun20XX Visual C++ 2015-20XX libraries (concrt140.dll,mfc140.dll,mfc140chs.dll,mfc140cht.dll,mfc140deu. ... Microsoft

Puedes seleccionar tantos componentes necesites o quieras instalar y continua con “OK”. Esto iniciará el proceso de instalación de todos los componentes seleccionados (Algunos como Microsoft Visual C++ Runtime requerirán dos procesos de instalación de componente) lanzando las ventanas de instalación necesarias. En este ejemplo de Microsoft Visual C++ Runtime requerirá que aceptes los términos y condiciones (Lectura opcional) y presiones en “Instalar”, espera a que se instale y al finalizar presiona “Cerrar” para continuar con el siguiente instalador de componente o finalizar el proceso.

Una vez terminado el proceso regresará a la pantalla inicial, la cual puedes cerrar si no necesitas nada más de Protontricks. Y ya está, ahora al ejecutar el juego no se mostrará el error de componentes de Microsoft.

 

 

También en Heroic Games Launcher. Si experimentas el error de componentes de Microsoft en un juego instalado mediante Heroic Games Launcher, puedes realizar el anterior proceso de forma integrada en la configuración, simplemente buscando “Winetricks” en la configuración del juego dentro del launcher.
