Prism como servidor API REST de pruebas

NodeJS
API
REST

Craiyon

Pablo Urrea

Lectura de 5 minutos
Publicado
15/04/2024

Muchas veces, en el mundo del desarrollo se convierte en la carrera de la liebre y la tortuga, y spoiler: tú no eres la liebre. Ese es el caso del desarrollo de API REST, donde las integraciones del API llegan mucho antes que la propia API, y necesitas ofrecer un entorno de pruebas a esa liebre que te mira mientras te adelanta y todas las semanas te manda un email pidiéndote una solución. Aquí es donde entra en juego Prism (Prisma para los amigos que no quieren quedarse mordiéndose los labios diciendo el nombre), una herramienta invaluable para simplificar y agilizar el proceso de desarrollo de APIs REST.yml

Prism es un servidor de simulación de API REST (Entre sus funcionalidades) que permite definir endpoints personalizados, simular respuestas y establecer escenarios de prueba para sus aplicaciones mediante la interfaz YML de OpenAPI. Con Prism, los equipos de desarrollo pueden crear un entorno de pruebas realista y controlado, sin depender de servidores externos o entornos de producción.

 

API REST Express. Configurar Prism es simple y rápido. Una vez instalado, puedes definir fácilmente endpoints, especificar el formato de las respuestas y simular diferentes estados de la API, como respuestas exitosas, errores o tiempos de espera. Prism ofrece una interfaz intuitiva que permite administrar las "falsas" API o API de prueba de manera eficiente. Con Prism, es posible definir escenarios de prueba complejos, simular datos dinámicos y validar el comportamiento de la aplicación en diferentes situaciones.

 

Instalación como cualquier otro paquete de NodeJs. Para comenzar a utilizar Prism, primero necesitas instalarlo en tu entorno de desarrollo (Obviamente). Puedes instalar Prism globalmente utilizando NPM (Node Package Manager) con el siguiente comando:

npm install -g @stoplight/prism-cli

Aunque también le puedes quitar el parámetro -g si no quieres que los paquetes de Node proliferen en tu máquina como roedores. Si necesitas más opciones de instalación puedes consultar la documentación de Prism.

 

Definiciones. Una vez que Prism esté instalado, puedes configurarlo para simular tu API REST. Supongamos que tienes una API con un endpoint /users que devuelve una lista de usuarios en formato JSON, el siguiente ejemplo de archivo de configuración YML muestra cómo configurar la simulación de este endpoint:

openapi: 3.0.0
info:
 title: Ejemplo de API REST
 version: 1.0.0
paths:
 /users:
   get:
     summary: Obtiene la lista de usuarios
     responses:
       '200':
         description: Respuesta exitosa
         content:
           application/json:
             schema:
               type: array
               items:
                 type: object
                 properties:
                   id:
                     type: integer
                   username:
                     type: string
                   email:
                     type: string

Este archivo lo puedes configurar a mano si te sientes lo bastante cómodo con la interfaz de configuraciones de OpenAPI, o con cualquier en cualquier herramienta de diseño de APIs, como por ejemplo SwaggerHub.

 

Arrancar todos los motores. Para ejecutar Prism y simular tu API REST, puedes hacerlo con el siguiente comando (Recuerda ajustar openapi.yml a la ruta del archivo de configuración anterior):

prism mock openapi.yml

Esto iniciará el servidor de pruebas en la URL http://localhost:4010, aunque acepta los siguientes parámetros combinables (Los más útiles):

  • -h: Modifica la dirección IP a la proporcionada. Por ejemplo:

    prism mock  -h 0.0.0.0 openapi.yml

  • -p: Modifica el puerto de red al proporcionado. Por ejemplo:

    prism mock  -p 9999 openapi.yml

  • --dynamic: Generará respuestas dinámicas que se ajusten al esquema proporcionado. Por ejemplo:

    prism mock  --dynamic openapi.yml

Una vez iniciado el servidor, ya se pueden realizar solicitudes al servicio desde tu máquina a la IP local (O a la IP de la máquina remota si se instala en un servidor remoto):

curl http://localhost:4010/users

Prism acepta configuraciones de métodos GET, POST, PUT, PATCH y DELETE.


Conclusión. Prism es una herramienta imprescindible para cualquier equipo de desarrollo que trabaje con APIs REST. Al simplificar el proceso de desarrollo y pruebas, esta permite a los equipos crear aplicaciones de alta calidad de manera más rápida y eficiente. Con sus características y su facilidad de uso, Prism se ha convertido en el compañero perfecto para cualquier desarrollador que busque mejorar su flujo de trabajo de desarrollo de APIs (O si simplemente no quieres quedarte atrás como la tortuga).

 

Si necesitas más información acerca del paquete, puedes consultar la documentación de Prism.
