¿Cómo instalar todas las actualizaciones pendientes con un solo comando en Windows?

Windows
Actualizaciones

Windows Package Manager (WinGet) (Fuente: Wikipedia)

Pablo Urrea

Lectura de 4 minutos
Publicado
07/02/2025

Desde que los ordenadores aparecieron en mi día a día tengo que reconocer que he polarizado a blanco o negro las actualizaciones pendientes, es decir, o comprobaba e instalaba las actualizaciones pendientes casi a diario o no lo hacía casi nunca. Si es cierto que en dispositivos móviles es más cómodo actualizar todas las aplicaciones desde la vista de actualizaciones en App Store o Play Store; en Linux se puede actualizar con un comando apt-get; pero, en Windows siempre he ido abriendo todas las aplicaciones de terceros una a una y comprobando actualizaciones, pero, ¿Y si te dijese que existe un comando en Windows para instalar todas las actualizaciones pendientes en programas instalados en el sistema?

 

CMD, el mayor aliado de Windows. Primero, hay que acceder a la consola CMD del sistema como administrador, para ello hay que presionar la tecla de “Windows 🪟” y escribir “CMD”. Aparecerá el Símbolo del sistema, para ejecutarlo como administrador simplemente hay que presionar el botón derecho del ratón y seleccionar “Ejecutar como administrador”. Tras confirmar su ejecución como usuario administrador, se abrirá la consola CMD en una nueva ventana.

 

WinGet para controlarlos a todos. Para comprobar que programas tienen una actualización pendiente de descargar e instalar hay que ejecutar Windows Package Manager (WinGet para los amigos):

winget upgrade

Este comando devolverá una tabla con información de estas actualizaciones pendientes.

 

Para actualizar un único paquete de esta lista, bastará con ejecutar el mismo comando seguido del ID del programa que se desea actualizar:

winget upgrade <id>

 

También existe una opción para actualizar toda la lista con el parámetro --all tras el comando:

winget upgrade --all

Esto tardará un momento dependiendo del número de actualizaciones disponibles pendientes de descargar e instalar y abrirá ventanas de actualización dependiendo de cada programa.

 

Si algún programa tiene una actualización no comprobada, es decir el sistema aún desconoce la existencia de esta actualización pendiente, es posible buscar actualizaciones para un programa con el comando search seguido del ID:

winget search <id>

 

Hay que tener en cuenta que WinGet soporta los siguientes formatos de instaladores directos, cualquier otro formato o pasos adicionales requerirá acciones manuales:

.exe .zip .inno .nsi .msi .wixproj .appx .msix

 

 

Conclusión. Aunque es posible que algunas actualizaciones sigan requiriendo tu atención y debas abrir los programas, pero la mayoría de estas las descarga e instala automáticamente sin problemas, por lo que en definitiva WinGet es una herramienta muy útil para automatizar esta tarea de mantenimiento en Windows. Si necesitas más información acerca de WinGet, puedes ejecutar winget --help en la consola o visitar Use the WinGet tool to install and manage applications.
