RosaZulado

TFG
XAMPP

Trabajo de fin de grado (TFG) que consiste en una aplicación web creada con un Servidor XAMPP (Apache, PHP, MariaDB) completamente funcional que realiza de forma autónoma la extracción de datos de productos eróticos de las principales páginas web de España mediante técnicas de web scraping y las categoriza e indexa periódicamente para comparar sus precios y mostrar al usuario el precio más barato del producto que busca.

RosaZulado es la primera aplicación web que compara precios y ofertas de las principales tiendas en línea de juguetes, productos y accesorios eróticos en España. Esta cuenta con un complejo sistema de filtrado y una extensa base de datos actualizada regularmente que muestra los productos que obtiene adaptando los resultados a lo que solicita el cliente. Estando toda la aplicación construida con AJAX (No requiere la recarga de la página al interactuar con ella), un sistema inteligente de búsqueda de productos que agiliza búsquedas realizadas previamente, la paginación de productos que muestra hasta 50 productos por página, y la API de seguridad diseñada exclusivamente para RosaZulado que elimina inyecciones en la base de datos de forma prácticamente instantánea, hacen que la experiencia de usuario sea la más ágil y rápida posible, haciendo que este se centre en encontrar la tienda que ofrece el producto que busca más barato. También, las tiendas pueden ver la información correspondiente a su tienda, pudiendo así realizar estadística de los productos que más buscan los clientes y el flujo de usuarios que recibe su página desde RosaZulado. Estos datos permanecerán seguros en su cuenta gracias al sistema de encriptación de 128 bytes aleatoria teniendo almacenada de forma segura su clave pública (Usuario) y su clave privada (Contraseña). Por último, RosaZulado también ofrece un servicio de examinación de usuarios que desean encontrar un juguete adaptado a sus necesidades.

 

Fuente: Trabajo de Fin de Grado: RosaZulado (El comparador de precios y ofertas de juguetes eróticos), 1. Naturaleza Del Proyecto, 1.1 Descripción Del Proyecto
