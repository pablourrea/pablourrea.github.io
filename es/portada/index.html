Ultimate Cron para dominar todas las tareas automáticas en Drupal

En Drupal, la gestión de tareas automáticas es crucial, pero el cron integrado puede ser limitante. Ultimate Cron ofrece una solución flexible que permite personalizar la frecuencia y programación de cada tarea, optimizando así el rendimiento del sitio y evitando sobrecargas en el servidor. En este artículo muestro como empezar a exprimir este módulo y utilizarlo eficiente y eficazmente.

Actualización selectiva de entidades durante migraciones de Drupal

Cuando se realizan migraciones en un sistema, a veces es necesario actualizar entidades existentes en lugar de crear nuevas. Sin embargo, este proceso puede ser complicado si solo se deben modificar algunas entidades específicas. Este artículo presenta distintos enfoques para facilitar la gestión de migraciones según las necesidades específicas de cada caso.

Migrar Paragraphs de Contenidos con Migrate (Versión mejorada)
